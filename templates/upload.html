Upload Menu Data

Upload a JSON file containing menu items with name, price, and calorie information.

JSON Format Example

[
  {
    "name": "Breakfast Burrito",
    "price": 6.99,
    "calories": 720
  },
  {
    "name": "Grilled Chicken Sandwich",
    "price": 8.49,
    "calories": 520
  }
]

Each item must have:

  • name: Item name (string)
  • price: Price in dollars (number)
  • calories: Calorie count (number)
