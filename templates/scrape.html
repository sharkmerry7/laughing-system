About Web Scraping

This tool attempts to automatically extract menu data from Cafe Bon Appetit websites.

Standard Scraping (Default)

  • Fast and lightweight
  • May be blocked by bot protection (403 errors)

Browser-Based Scraping (Selenium)

  • Simulates a real browser
  • Better at bypassing bot protection
  • Requires Chrome and chromedriver to be installed
  • Slower than standard scraping

Troubleshooting

If scraping fails:

  • Try the browser-based scraping option
  • Check if the URL is correct
  • The website structure may have changed
  • As an alternative, manually save the menu data and use the Upload feature

Example URLs

  • https://sony.cafebonappetit.com
  • https://[your-location].cafebonappetit.com
